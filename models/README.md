# 3D 模型資產目錄（`.glb`）

將 Tripo AI 或 Meshy 匯出的輕量 `.glb` 檔案（建議單檔 1–3 MB 以內）放入此資料夾，兩款 3D 遊戲會自動載入並替換對應的程式化角色與道具（未放入時自動顯示內建 3D 模型）：

## 《柴犬滑行 3D》（`shiba-slide-3d.html`）
* `shiba-skier.glb` — 柴犬滑雪音樂冒險家主角（支援骨骼動畫 `AnimationMixer`）
* `snowboard-note.glb` — 音符塗裝滑雪板
* `snowman-conductor.glb` — 戴指揮帽的音樂雪人障礙
* `coin-note.glb` — 金色八分音符金幣
* `ramp-crystal.glb` — 冰晶音符跳台

## 《節奏衝浪 3D》（`rhythm-surf-3d.html`）
* `cyber-shiba-dj.glb` — 賽博柴犬 DJ 衝浪手主角（支援骨骼動畫 `AnimationMixer`）
* `hoverboard-neon.glb` — 雙噴射霓虹懸浮衝浪板

## 《立體琴鍵島 3D》（`chord-island-3d.html`）
* `shiba-pianist.glb` — 燕尾服小柴犬鋼琴家主角（紫色燕尾服、紅領結、白手套，支援骨骼動畫 `AnimationMixer`）
